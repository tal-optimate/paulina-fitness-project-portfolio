# פאולינה פיטנס — תיק פרויקט אוטומציות ולוחות

תיק פרויקט (Project Portfolio) בעברית המרכז את כל האוטומציות והתשתית של פאולינה פיטנס.

הדף (`index.html`) הוא קובץ עצמאי אחד ללא תלויות חיצוניות, ומחולק לשתי לשוניות:

- **⚙️ אוטומציות** — כל תרחישי Make.com וה-workflows של n8n, מתועדים בשפה עסקית פשוטה (טריגר, שלבים, מערכות מחוברות).
- **📋 monday** — הלוחות של הפרויקט: מבנה הנתונים, השדות, הקבוצות ומספר הרשומות בכל לוח.

כולל חיפוש חי, סינון לפי פלטפורמה/סטטוס, וכרטיסים מתקפלים.

הוכן ע״י **Optimate**.
